# v0.8.3 智能简报设计

## 目标

把“日报”升级为“智能简报”。简报不再默认套开发机会模板，而是根据关注对象、来源和内容意图自动选择模板。用户可以继续手动切换模板，但默认路径应尽量自动：关注人生成观点追踪，关注问题生成问题进展，话题/热榜生成趋势简报，工作台/项目生成研究简报，命中开发关键词时才生成开发机会报告。

## 模板

- 开发机会报告：适用于 AI 工具、开源、产品化、开发者工具、KMP、DSH、工程效率等线索。
- 人物观点追踪：适用于关注的人、作者、答主及其回答/创作。
- 问题进展追踪：适用于问题链接、问题追踪、新回答聚合。
- 话题趋势简报：适用于热榜、推荐流、关键词、话题型内容。
- 研究项目简报：适用于工作台、研究项目和一组沉淀材料。
- 收藏复盘：适用于收藏夹、稍后读、已收藏内容。

## 路由规则

第一版使用规则路由，不引入额外模型分类：

1. source 或 url 命中作者/关注的人/创作 → 人物观点追踪。
2. url 包含 `/question/` 或 source 命中问题/未读追踪 → 问题进展追踪。
3. source 命中研究项目/工作台且条目已沉淀 → 研究项目简报。
4. source 命中收藏/稍后读 → 收藏复盘。
5. 标题/摘要/source 命中开发关键词 → 开发机会报告。
6. 其他混合热榜/动态 → 话题趋势简报。

路由结果需要展示给用户：自动选择了哪个模板、为什么选择、使用了哪些数据源。用户可手动切换模板重新生成。

## UI

机会报告页新增“智能简报”卡片：

- 显示自动模板、路由原因、候选数、高优先级数。
- 下拉选择模板。
- 按钮：生成今日智能简报、重新生成、复制简报。
- 展示最近 7 天简报历史。

机会报告候选列表和原 DSH 机会报告按钮继续保留。智能简报是更主动的日报入口，机会报告是候选分析入口。

## 全局提醒

v0.8.3 先做基础状态：client 在 `shell.overlay` 注册一个轻量提醒 pill，读取本地简报状态并提示：

- 今日智能简报已生成。
- 今日尚未生成，点击打开知乎面板。
- 最近生成失败。

后续版本再加定时调度和自动弹出 toast。

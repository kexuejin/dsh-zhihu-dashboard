# v0.8.4 数据源收口设计

## 目标

移除用户界面中的浏览器 Cookie/profile 路径，把账号态内容统一表述为“知乎只读登录态”。浏览器 Cookie 自动读取在 macOS Chrome/Edge/Arc 等环境中经常遇到系统加密，体验不稳定，不应继续作为推荐入口。

## 当前策略

- Access Secret 继续作为当前主路径。
- 用户可见的账号态入口改为“知乎扫码登录（推荐）”。
- v0.8.4 先提供设置页占位和安全说明，不实现扫码登录状态机。
- 机会报告页移除浏览器会话快捷入口和浏览器会话筛选。
- 数据源统计中保留通用“会话”概念，为后续扫码登录复用。
- 底层 browser-session API 暂时保留为内部 fallback，不再暴露用户入口。

## 安全说明

扫码登录后仍按只读会话处理：不保存账号密码，Cookie 不进入模型、导出或日志。后续实现必须提供清除会话能力。

## 后续

下一版实现扫码登录状态机：生成二维码、轮询扫码/确认状态、保存只读会话、清除会话，并让智能简报/关注内容读取优先使用该会话。
